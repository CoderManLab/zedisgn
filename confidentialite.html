Confidentialité

Des échanges simples, sans collecte inutile.

Cette page décrit le fonctionnement actuel du site ZEDESIGN concernant les informations saisies et les services tiers.

Brouillon local facultatif

Si vous cochez « Conserver mon brouillon sur cet appareil », les champs du brief sont enregistrés dans le stockage local de ce navigateur. Ils ne sont pas envoyés à ZEDESIGN. Le brouillon est conservé 7 jours et supprimé à la prochaine visite après expiration. Vous pouvez aussi l’effacer depuis le formulaire. Évitez cette option sur un appareil partagé.

Brief et assistant

Le brief express et l’assistant préparent un message dans votre navigateur. Ce contenu n’est pas envoyé directement à ZEDESIGN. L’ouverture d’un lien WhatsApp transmet le message préparé à ce service ; vous choisissez ensuite de l’envoyer.

WhatsApp

Lorsque vous ouvrez WhatsApp, vous quittez ZEDESIGN et les règles de confidentialité de WhatsApp s’appliquent à l’échange.

Hébergement

Le site est hébergé via GitHub Pages. Des données techniques nécessaires à la fourniture du service peuvent être traitées par l’hébergeur.

Données sensibles

N’envoyez pas d’informations sensibles via le brief ou le chatbot. Un premier échange doit rester limité aux informations utiles au projet.
